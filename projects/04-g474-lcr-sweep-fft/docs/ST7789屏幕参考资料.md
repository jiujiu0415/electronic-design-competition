## 2. 模块引脚定义 (FPC 10-pin)

从电路原理图解析：

| Pin | 丝印 | 功能 | 连接 MCU |
|-----|------|------|----------|
| 1 | GND | 地 | GND |
| 2 | TSR | 复位 (RESX), 低有效 | GPIO (PA8) |
| 3 | LCS | 片选 (CSX), 低有效 | GPIO (PB1) |
| 4 | CD | 命令/数据选择 (D/CX) | GPIO (PB0) |
| 5 | SC | 串行时钟 (SCL) | SPI2_SCK (PB13) |
| 6 | ADS | 串行数据输入 (SDA/MOSI) | SPI2_MOSI (PB15) |
| 7 | ODS | 串行数据输出 (SDO/MISO) | SPI2_MISO (PB14) 可选 |
| 8 | CCV | 电源 3.3V | 3.3V |
| 9 | A | 背光 LED 阳极 | 3.3V (或 PWM 控制) |
| 10 | K | 背光 LED 阴极 | GND (或限流电阻到 GND) |

### 原理图关键细节:
- **上拉电阻**: SER(SDA)、LCS(CS)、CD(D/C)、SC(SCL)、ADS 各通过 4.7KΩ 上拉到 3.3V
- **ESD 保护**: 所有 SPI 信号线有 5819 肖特基二极管保护
- **电源**: 板载 xc6206 3.3V LDO，输入 VCC → 输出 3.3V
- **背光**: A 脚到 3.3V 通过限流电阻，K 脚到 GND
- **复位**: TSR 引脚低有效，模块内部可能有上拉

## 3. ST7789VW 控制器核心信息

### 3.1 接口配置

4-line SPI 模式 I: `IM[3:0] = 0110`

| 信号 | 方向 | 说明 |
|------|------|------|
| CSX | IN | 片选，低有效 |
| D/CX | IN | 0=命令, 1=数据/参数 |
| SCL | IN | 时钟，数据在上升沿锁存 |
| SDA | IN/OUT | 数据输入输出 |
| SDO | OUT | 数据输出 (可选，读回时用) |

### 3.2 SPI 时序参数

| 参数 | 最小值 | 说明 |
|------|--------|------|
| SCL 周期 (写) | 16 ns | 理论最大 62.5 MHz |
| SCL 周期 (读) | 150 ns | ~6.7 MHz |
| SCL 高电平脉宽 | 7 ns | |
| SCL 低电平脉宽 | 7 ns | |
| CSX 建立时间 | 15 ns | |
| CSX 保持时间 | 15 ns | |
| D/CX 建立时间 | 10 ns | |
| D/CX 保持时间 | 10 ns | |
| SDA 建立时间 | 7 ns | |
| SDA 保持时间 | 7 ns | |

> 实际使用: STM32G4 SPI 外设 ≤ 40 MHz 均可正常工作

### 3.3 数据传输格式 (4-line SPI)

```
CSX  ____|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|_____
         ↓ 开始传输
D/CX ____|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|_____
         0=命令  1=数据
SCL  ____|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_____
          ↑ 上升沿采样
SDA  ----X D7 X D6 X D5 X D4 X D3 X D2 X D1 X D0 ----
          MSB first

每个字节:
  D/CX=0 → 命令字节
  D/CX=1 → 参数/数据字节
  MSB 先传, 上升沿锁存
```

### 3.4 关键命令速查表

| 命令 | 代码 | 参数 | 说明 |
|------|------|------|------|
| NOP | 0x00 | - | 空操作 |
| SWRESET | 0x01 | - | 软件复位, 等 5ms (Sleep In 时等 120ms) |
| RDDID | 0x04 | 读 4 字节 | 读 ID: 默认 0x85 0x85 0x52 |
| SLPIN | 0x10 | - | 睡眠模式 |
| SLPOUT | 0x11 | - | 退出睡眠, 等 120ms 再发下一条 |
| PTLON | 0x12 | - | 局部显示模式 |
| NORON | 0x13 | - | 正常显示模式 (默认) |
| INVOFF | 0x20 | - | 关闭反色 |
| INVON | 0x21 | - | 开启反色 |
| DISPOFF | 0x28 | - | 关闭显示 |
| DISPON | 0x29 | - | 开启显示 |
| **CASET** | **0x2A** | XS15-8, XS7-0, XE15-8, XE7-0 | 列地址窗口 (0~239) |
| **RASET** | **0x2B** | YS15-8, YS7-0, YE15-8, YE7-0 | 行地址窗口 (0~319) |
| **RAMWR** | **0x2C** | 像素数据 D1..Dn | 写帧内存 (RGB565) |
| RAMRD | 0x2E | 读像素 | 读帧内存 (18-bit) |
| **MADCTL** | **0x36** | 1 字节 | 内存访问控制 (方向/颜色顺序) |
| **COLMOD** | **0x3A** | 1 字节 | 像素格式: 0x55=16bit, 0x66=18bit |
| WRDISBV | 0x51 | 1 字节 | 背光亮度 (0x00~0xFF) |

### 3.5 COLMOD (0x3A) — 像素格式

| 参数值 | 含义 | 常用 |
|--------|------|------|
| 0x33 | 12-bit/pixel RGB444 | |
| **0x55** | **16-bit/pixel RGB565** | ✅ 推荐 |
| 0x66 | 18-bit/pixel RGB666 | 默认 |

### 3.6 MADCTL (0x36) — 内存访问控制

| Bit | 名称 | 功能 | 常用值 |
|-----|------|------|--------|
| D7 | MY | 行地址方向 | 0=上→下, 1=下→上 |
| D6 | MX | 列地址方向 | 0=左→右, 1=右→左 |
| D5 | MV | 行列交换 | 0=正常, 1=交换 |
| D4 | ML | 刷新方向 | 0=上→下, 1=下→上 |
| D3 | RGB | RGB/BGR 顺序 | 0=RGB, 1=BGR |
| D2 | MH | 锁存方向 | 0=左→右, 1=右→左 |

**常用配置:**
- 竖屏, 左上角原点: `0x00`
- 横屏, 左上角原点: `MV=1, MX=1, MY=1` → `0x60` 或 `0xE0` (需实测)
- BGR 颜色顺序: 设 `RGB=1` → `0x08`

### 3.7 画面写入流程

```
1. CASET(0x2A): 设定列范围 XS..XE (0..239)
2. RASET(0x2B): 设定行范围 YS..YE (0..319)
3. RAMWR(0x2C): 发送像素数据 (每个像素 2 字节 RGB565)
```

## 4. 初始化序列 (推荐)

```c
// 参考标准 ST7789 初始化 (已对照数据手册)

// 1. 硬件复位
RST_Low();   delay_ms(10);
RST_High();  delay_ms(120);

// 2. 软件复位
WriteCmd(0x01);  // SWRESET
delay_ms(150);   // Sleep In 模式下等 120ms

// 3. 退出睡眠
WriteCmd(0x11);  // SLPOUT
delay_ms(120);   // 手册要求等 120ms

// 4. 像素格式: 16-bit RGB565
WriteCmd(0x3A);  // COLMOD
WriteData(0x55); // RGB565

// 5. 内存访问控制
WriteCmd(0x36);  // MADCTL
WriteData(0x00); // 竖屏, RGB 顺序

// 6. 显示反色 (ST7789 通常需要)
WriteCmd(0x21);  // INVON

// 7. 正常显示模式 (确保不在局部模式)
WriteCmd(0x13);  // NORON

// 8. 开启显示
WriteCmd(0x29);  // DISPON
delay_ms(20);
```

## 5. 颜色编码 RGB565 (16-bit)

```
15 14 13 12 11 | 10  9  8  7  6 | 4  3  2  1  0
 R4 R3 R2 R1 R0| G5 G4 G3 G2 G1| B4 B3 B2 B1 B0
 ←── 红色 ──→ | ←── 绿色 ──→ | ←── 蓝色 ──→

uint16_t color = ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3);
// r,g,b 范围: 0~255

常用颜色:
  黑色:   0x0000
  白色:   0xFFFF
  红色:   0xF800
  绿色:   0x07E0
  蓝色:   0x001F
  黄色:   0xFFE0
  青色:   0x07FF
  洋红:   0xF81F
  灰色:   0x8410
```

## 6. 与 MCU 连接注意事项

1. **SPI 引脚电平**: ST7789VW VDDI = 1.65~3.3V, STM32G474 是 3.3V I/O → 直连安全
2. **背光控制**: A 脚直连 3.3V 最亮, 接 MCU PWM 可调亮度
3. **SDO (MISO)**: 可选, 不用读回功能可以不连
4. **上拉电阻**: 模块板载 4.7K 上拉, 不需要外加
5. **CSX 接地**: 手册说可以永久接地 (只操作一个 SPI 设备时), 但建议用 GPIO 控制
