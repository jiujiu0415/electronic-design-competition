# LCR 网络基础

> LCR = 电感 (Inductor L) + 电容 (Capacitor C) + 电阻 (Resistor R)
> LCR 网络 = 用这三种元件搭建的电路

---

## 1. 为什么要测"频率响应"？

同一个电路对不同频率的信号反应不同。举个例子：

- 你把 100Hz 的信号输入一个电路，输出可能跟输入差不多
- 你把 100kHz 的信号输入同一个电路，输出可能变得很小
- 频率响应就是告诉你：**每个频率下，输出跟输入的关系**

就像耳朵测听力：不同频率的声音，你能听到的音量不一样。LCR 网络也一样。

---

## 2. 基本概念

### 阻抗 (Impedance)

每个元件对不同频率的"阻力"不同：

| 元件 | 阻抗公式 | 低频 | 高频 |
|------|----------|------|------|
| 电阻 R | Z = R | 不变 | 不变 |
| 电容 C | Z = 1/(jωC) | 很大 (阻断) | 很小 (导通) |
| 电感 L | Z = jωL | 很小 (导通) | 很大 (阻断) |

> ω = 2πf，所以频率越高 ω 越大

### 传输函数 H(jω)

```
H(jω) = Vout / Vin  (复数!)

幅度响应: |H(jω)| = |Vout| / |Vin|     → 画幅频曲线
相位响应: ∠H(jω) = ∠Vout - ∠Vin       → 画相频曲线
```

## 3. 常见的 LCR 网络

### 3.1 RC 低通滤波器

```
  R
──\/\/\──┬── Vout
         │
        === C
         │
─────────┴── GND
```

- 传输函数: H(jω) = 1 / (1 + jωRC)
- 截止频率: fc = 1 / (2πRC)
- 幅频: f < fc 时 ≈ 1（通过），f > fc 时逐衰减
- 相频: 从 0° 逐渐到 -90°

**示例**: R=1kΩ, C=100nF → fc ≈ 1.6kHz

### 3.2 RC 高通滤波器

```
        === C
        │
───────┬┴── Vout
       │
      ┌┴┐ R
      │ │
      └┬┘
       │
───────┴── GND
```

- 截止频率同低通, 但 f < fc 衰减, f > fc 通过

### 3.3 LC 谐振电路

```
  L
──))))──┬── Vout
        │
       === C
        │
────────┴── GND
```

- 谐振频率: fr = 1 / (2π√(LC))
- 在 fr 处阻抗最小 → 输出最大（带通特性）
- 品质因数 Q 决定"峰有多尖"

### 3.4 分压式 LCR

```
     Z1
──/\/\/\──┬── Vout
          │
         Z2
         │
─────────┴── GND
```

Z1、Z2 可以是 R/L/C 任意组合，传输函数 = Z2/(Z1+Z2)

## 4. 扫频测量实际操作

1. 面包板上搭好你的 LCR 网络（两个端口：输入 + 输出）
2. 输入端：接 AD9833 信号输出
3. 输入参考：用杜邦线从输入端并联到 PA0 (ADC1_IN1)
4. 输出端：接 PA1 (ADC1_IN2)
5. 地线：AD9833、LCR 网络、STM32 三者共地

```
AD9833 ──── Z1 ──┬── Z2 ──── GND
                 │
         ┌───────┤
         │       └────────── PA1 (ADC1_IN2 = Vout)
         │
         └────────────────── PA0 (ADC1_IN1 = Vin 参考)
```

## 5. 幅频曲线怎么看 (Bode 图)

```
增益(dB)
  ^
 0┤~~~~~~~~~~~~                     ← 通带
  │          ╲
  │           ╲
-3┤- - - - - - -╲- - - - - - - -   ← 截止频率
  │             ╲
  │              ╲╲╲╲╲╲╲╲╲╲╲    ← 阻带 (-20dB/decade)
  └────────────────────────────→ f (log)
```

- 增益用 dB 表示: `dB = 20 × log10(|Vout|/|Vin|)`
- 0 dB = 输入输出一样大
- -3 dB = 输出是输入的 70.7%（截止频率判定标准）
- -20 dB = 输出是输入的 10%

## 6. 实验建议

拿到板子后，先搭一个 **RC 低通滤波器** (R=1kΩ, C=100nF) 做测试：

- 截止频率 ~1.6kHz，频率响应曲线形状明确
- 元器件简单，容易焊接/插面包板
- 如果扫频结果跟理论计算吻合 → 整个系统验证通过

后续可以尝试：
- 测不同 RC 组合并对比理论值
- 测 LC 谐振电路（找谐振峰）
- 测未知电路并反推元件值
