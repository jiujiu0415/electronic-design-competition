# 双 AD9833 驱动 — 集成到 CubeIDE 工程

## 文件位置

把刚才写的两个文件放到 CubeIDE 生成的工程里：

```
dual_ad9833_fft/
├── Core/
│   ├── Inc/
│   │   └── ad9833.h          ← 放这里
│   └── Src/
│       ├── ad9833.c          ← 放这里
│       └── main.c            ← 改这个
```

> CubeIDE 在 Project Explorer 里会自动识别并编译到工程里，不需要手动加路径。

---

## main.c 里要改的地方

### ① 顶部: 加 include

```c
/* USER CODE BEGIN Includes */
#include "ad9833.h"
#include <stdio.h>      // printf 用
/* USER CODE END Includes */
```

### ② main() 里: 在初始化区加入

找到这行下面:

```c
/* Initialize all configured peripherals */
MX_GPIO_Init();
MX_SPI1_Init();
// ... 其他 MX_xxx_Init() ...
```

在 `/* USER CODE BEGIN 2 */` 里:

```c
/* USER CODE BEGIN 2 */

/* 初始化两颗 AD9833, 默认输出 1kHz 正弦波 */
AD9833_Init(AD9833_MODULE_1);
AD9833_Init(AD9833_MODULE_2);

/* 分别设不同频率验证两个模块独立工作 */
AD9833_SetFreq(AD9833_MODULE_1, 5000.0f);   // 模块1 → 5kHz
AD9833_SetFreq(AD9833_MODULE_2, 10000.0f);  // 模块2 → 10kHz

printf("Dual AD9833 ready.\r\n");
printf("Module 1 (PA4): 5kHz sine\r\n");
printf("Module 2 (PA6): 10kHz sine\r\n");

/* USER CODE END 2 */
```

### ③ 主循环里暂空

```c
/* USER CODE BEGIN WHILE */
while (1)
{
    /* 后面会在这里加 ADC 采集 + FFT 处理 */
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
}
/* USER CODE END 3 */
```

## 串口 printf 重定向 (这样 printf 才能从 ST-LINK VCP 输出)

在 `main.c` 的 `/* USER CODE BEGIN 0 */` 区域加:

```c
/* USER CODE BEGIN 0 */

#ifdef __GNUC__
/* STM32CubeIDE 用的 GCC 编译器 */
int _write(int fd, char *ptr, int len)
{
    HAL_UART_Transmit(&huart2, (uint8_t *)ptr, len, 100);
    return len;
}
#endif

/* USER CODE END 0 */
```

## 编译 & 烧录

1. **Ctrl+B** 编译 → 0 Error
2. USB 线连 NUCLEO 板到 PC
3. **Run → Run** (或 绿色 ▶ 按钮) 烧录
4. 打开串口工具 (PuTTY / CubeIDE Terminal, 115200 8N1)
5. 看到 `Dual AD9833 ready.` 输出 → 成功

## 用示波器验证

| 测哪里 | 预期波形 |
|--------|---------|
| AD9833 #1 VOUT ↔ GND | **5kHz 正弦波**, ~0.6Vpp, 偏置 ~0.3V |
| AD9833 #2 VOUT ↔ GND | **10kHz 正弦波**, ~0.6Vpp, 偏置 ~0.3V |

两个波形应该频率不同、各自稳定，证明 SPI 总线共享 + 独立 FSYNC 机制正常工作。

## 常见问题

| 现象 | 排查 |
|------|------|
| 两个模块都没波形 | 示波器量 PA4/PA6: 空闲应该高电平。量 SCK=PA5: 发数据时有时钟闪烁 |
| 只有一个有波形 | 检查没波形的那个 FSYNC 杜邦线是否接触良好 |
| 串口没输出 | 确认 USART2 的 TX/RX 引脚和 NUCLEO 板一致 (可能是 PA2/PA3 或 PD5/PD6) |
| 编译报 `FSYNC1_Pin` 未定义 | CubeMX 里 PA4 的 User Label 没写 `FSYNC1`。回去改, 重新生成代码 |

## 跟原来 F103 版本的调用区别

| F103 版本 | G474 双模块版本 |
|-----------|----------------|
| `AD9833_Init()` | `AD9833_Init(1)` 或 `AD9833_Init(2)` |
| `AD9833_SetFreq(f)` | `AD9833_SetFreq(1, f)` 或 `AD9833_SetFreq(2, f)` |
| `AD9833_SetWave(w)` | `AD9833_SetWave(1, w)` 或 `AD9833_SetWave(2, w)` |

多了一个参数，其他完全一样。
