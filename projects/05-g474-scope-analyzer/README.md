## 目标

设计制作周期信号测量分析装置，对信号源（50Ω输出阻抗）输出的周期信号进行：
- **时域**：显示波形（1或3个完整周期）、Vpp、真有效值 Vrms、基频 f₁
- **频域**：显示电压频谱图、各谐波分量幅值
- **频率分辨率**：500Hz
- **供电**：单路 5V DC
- **显示屏**：≥6 英寸

---

## 三大测试要求

| | 输入 | Vpp 范围 | 频率范围 | 干扰 | 分值 |
|---|------|---------|----------|------|------|
| 要求1 | u = uₐ | 100~250mV | 10k~200kHz | 无 | 33 |
| 要求2 | u = u_b | 50~250mV | 10k~500kHz | 无 | 33 |
| 要求3 | u = u_b + u_J | u_b: 50~250mV, u_J: 200mV | u_b: 10k~500k, u_J: ≥1MHz | 有（需抑制） | 34 |

每项要求含 4 个子任务：

| 子任务 | 内容 | 误差要求 | 分值 |
|--------|------|---------|------|
| (1) 波形显示 | 一键切换 1个/3个完整周期波形 | — | 6 |
| (2) 时域测量 | Vpp、Vrms、基频 f₁ | Vpp/Vrms≤5mV, f₁≤1kHz | 13/15 |
| (3) 频谱图 | 定性显示电压频谱（谱线根数/位置/比例） | 大致吻合 | 5 |
| (4) 谐波幅值 | 各频率分量幅值 | ≤5mV | 8/9 |

**设计报告**：20 分 | **总分**：120

## 信号特性

- uₐ 和 u_b 均由 **基波 + 1~2 个谐波分量** 组成
- 示例表达式：
  ```
  u = U₁·sin(2π·10.5k·t) + U₃·sin(2π·31.5k·t) + U₄·sin(2π·42.0k·t) mV
  → 频谱显示：10.5kHz(U₁), 31.5kHz(U₃), 42.0kHz(U₄)
  ```
- Vrms 必须为 **真有效值**（时域积分，非频域推算）
- 频谱为 **正频率轴上离散谱线**

## 关键技术难点

| 难点 | 描述 | 方案思路 |
|------|------|---------|
| **抗混叠滤波** | 1MHz 干扰（200mVpp）必须在 ADC 前滤掉，否则混叠 | 有源低通，截止 ~550kHz，≥3阶 |
| **高速采样** | 500kHz 信号需 ≥1MSPS，分辨率 500Hz 需 ≥2000 点 FFT | 2MSPS + 4096 点 FFT |
| **大屏驱动** | 现有 2.4" ST7789 不满足 ≥6" 要求 | 串口 HMI 屏（UART）或并口大屏 |
| **真有效值** | 不是 peak/√2，是真正的 RMS 积分 | 从 ADC 采样数据直接算 sqrt(mean(v²)) |
| **周期截取** | 显示精确 1/3 周期需知道基频 | FFT 测基频 → 计算每周期采样点数 → 截取 |
