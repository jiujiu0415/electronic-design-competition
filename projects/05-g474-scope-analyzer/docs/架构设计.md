## 1. 信号链路（已确认）

```
u_b (50-250mVpp, 10k-500kHz, AC) ─┐
                                   ├→ 加法器 → 混合信号 ┬→ AD603 AGC → 1.6V偏置 → 混合信号A → ADC1(PA0)
u_J (200mVpp, ≥1MHz, AC) ────────┘                    │
                                                       └→ 检波器 → 跟随器 → 混合信号B → ADC2(PA1)
```

- ADC1：采 AGC 放大后的信号（0~3.2V 单极性，1.6V 偏置）
- ADC2：采检波器直流输出 → 反推 AGC 前总 Vpp → 计算 AGC 增益
- 两个 ADC 由 TIM2 TRGO 同步触发 @2.0 MSPS

## 5. 干扰处理：运行时检测（❌ 不用宏开关）

不做 `SCOPE_DUAL_ADC` 编译时切换。代码始终编译双 ADC 支持，运行时自动判断：

| 场景 | ADC2 状态 | 行为 |
|------|-----------|------|
| 要求 1/2（无干扰） | 可能未接 | 检波器读数 < 阈值 → agc_gain=1.0，无干扰处理 |
| 要求 1/2（有 AGC） | 已接 | 检波器正常读数 → 计算 agc_gain，无干扰峰 |
| 要求 3（有干扰） | 已接 | 检波器读数 → agc_gain，FFT 中检测非整数倍峰 → 标记排除 |

干扰识别逻辑不变（层① 整数倍验证 + 层② 幅值匹配），没检测到干扰峰就是没有，有就滤掉。

**ADC2 未连接检测**：若 `vpp_envelope < 10mV`（检波器输出接近 0），认为未连接，agc_gain = 1.0，跳过干扰分析。

## 6. ADC 精度提升方案（设计讨论）

### 6.1 硬件过采样（OVS）— G474 内置，推荐优先做

G474 ADC 硬件支持过采样引擎（ADCx_CFGR2）：
- 2× ~ 256× 过采样
- 自动累加 + 右移 → 分辨率提升（12-bit → 最高 16-bit）
- 不增加 CPU/DMA 负担

| 过采样比 | 额外位数 | SNR 提升 | 等效分辨率 |
|----------|----------|----------|------------|
| 4× | +1 bit | +6 dB | 13-bit |
| 16× | +2 bit | +12 dB | 14-bit |
| 64× | +3 bit | +18 dB | 15-bit |
| 256× | +4 bit | +24 dB | 16-bit |

代价：等效采样率降低。256× OVS 时 2MSPS → 7.8 kSPS，不可用。
16× OVS 时 2MSPS → 125 kSPS，对 500kHz 信号仍满足 Nyquist。

**待讨论**：OVS 倍数选多少？是否需要 CubeMX 重新配置？

### 6.2 双 ADC 交替采样（Interleaved）— G474 支持

ADC1 + ADC2 对同一引脚交替采样：
- 两路各 2MSPS，相位差 180° → 等效 4MSPS
- 好处：时间分辨率翻倍，对高频谐波检测更准
- 代价：ADC2 不能再用于检波器

**如果用此方案**：检波器改到 ADC3（PA2 或其他引脚）。G474 有 5 个 ADC，资源足够。

### 6.3 同步采样 — 已实现

ADC1 和 ADC2 已由同一 TIM2 TRGO 触发，采样时刻对齐。无需改动。

### 6.4 过采样 + 交替采样 叠加？

- 16× OVS + 双交替：等效 4MSPS / 16 = 250 kSPS，对 500kHz 信号 Nyquist = 125kHz，**不够**。
- 4× OVS + 双交替：等效 4MSPS / 4 = 1 MSPS，对 500kHz 信号刚刚够 Nyquist，**勉强**。
- 不用 OVS + 双交替：等效 4MSPS，Nyquist = 2MHz，对 500kHz 够，对 ≥1MHz 干扰仍会混叠。

**初步结论**：如果要检测 ≥1MHz 干扰的频率，双交替 4MSPS 有意义。如果只是滤掉干扰（不关心其频率），当前 2MSPS 够用。

### 6.5 其他改进项

| 方法 | 效果 | 复杂度 |
|------|------|--------|
| 多轮采集平均（采 N 轮 4096 再做 FFT） | 降噪 √N，频谱更干净 | 低，纯软件 |
| ADC 采样时间延长 | 减少 ADC 内部 RC 充放电误差 | CubeMX 改参数 |
| 内部 VREF 替代 VDD 做参考 | 温漂更小 | CubeMX 改配置 |
| 差分模式 | 共模抑制 | 需改硬件接线 |
