## 1. 信号链路（已确认）

```
                          ┌── 模拟开关(GPIO控制) ──┐
                          │                        │
u_b (多谐波, 50-250mVpp,  ─┐                       │
     10k-500kHz, 双极性)   │                       │
                           ├──→ [加法器] ─→ [LPF 700kHz] ─→ [AD603 AGC] ─→ [DC偏置] ─→ ADC1+2
u_J (干扰, 200mVpp,       │                       │         ×G→3Vpp       (单极性)   (交替4MSPS)
     ≥1MHz, 双极性) ──────┘                       │           │
                                                  │           │
                                                  └──→ [检波器] → [跟随器] → ADC3
                                                          直流电压                (独立采样)
```

| 环节 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 信号源 | u_b + u_J，两路双极性独立 | — | 信号发生器 50Ω 输出 |
| 模拟开关 | u_J | u_J 或 断开 | **STM32G474 GPIO 控制**，要求1/2断开，要求3闭合 |
| 加法器 | u_b (+ u_J) | 叠加波形，双极性 | AD835 乘法器用作加法器 |
| LPF | 加法器输出 | 滤波后波形 | 截止频率 **700kHz**，衰减 ≥1MHz 干扰 |
| AD603 AGC | 滤波后波形 | 增益到 **3Vpp**，双极性 | 自动增益控制 |
| DC偏置 | AGC输出 | 0~3.3V 单极性 | 偏置衰减忽略，仍按 3Vpp 计算 |
| ADC1+2 | DC偏置后 | 4096点 @交替4MSPS | **双 ADC 硬件交替**，Nyquist=2MHz |
| 检波器 | AGC 输出（引出） | 直流电压 ∝ AGC输出Vpp | 包络检波，与 AGC 放大倍数有确定关系 |
| 跟随器 | 检波器输出 | 低阻抗直流 | 驱动 ADC3 |
| ADC3 | 跟随器输出 | 直流电压值 | 独立于 ADC1/2 |

### 关键设计决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 检波器在 **AGC 输出端**（非输入端） | 硬件接线如此；通过校准曲线 G=f(Vd) 反推增益 |
| 2 | AGC 输出固定 **3Vpp**（非之前的 3.2V） | 实际电路标定值 |
| 3 | LPF **700kHz** 硬件滤波 | 衰减 ≥1MHz 干扰，辅助软件识别 |
| 4 | 模拟开关由 **STM32G474 GPIO PA4** 控制 | 单片机物理切换 u_J 是否接入 |
| 5 | DC偏置衰减**忽略** | 幅度衰减在整体校准中已隐含补偿 |
| 6 | 双 ADC 交替 **4MSPS** (ADC1+2 Interleaved on PA0) | Nyquist=2MHz, DMA CDR 32-bit, FFT 8192 |
| 7 | 基频 **500Hz 吸附** | 题目约束：f₁ = N × 500Hz |
| 8 | ADC3 (PB1) 独立采集检波器 | 软件触发单次, 12-bit, Fast Channel |

## 2. 核心计算链

```
                      ADC3 ──→ Vd(mV) ──→ [G = f(Vd)] ──→ G (AGC放大倍数)
                                       二次拟合 42点校准       │
                                                             ↓
                                              Vpp_filtered = 3000 / G  (mVpp)
                                              （AGC 输入端 Vpp）
                                                             ↓
ADC1+2 ──→ FFT 8192点 ──→ 峰值检测 ──→ f₁_raw ──→ [500Hz吸附] ──→ f₁ = N×500Hz
              │              │
              ▼              ▼
          Hann窗+修正    抛物线插值幅度 → Vpeak_adc[k]
              │              │
              ▼              ▼
         相位提取         Vpeak_preAGC[k] = Vpeak_adc[k] / G
              │              │
              └──────┬───────┘
                     ▼
          时域重建 u_b[n] = Σ Vpeak_preAGC[k] × sin(2π×f_k×n/Fs + φ_k)
                     │
                     ▼
          Vpp_agc_input = max − min
                     │
                     ▼
          Vpp_original = Vpp_agc_input / H_chain(f₁)
          Vpeak_original[k] = Vpeak_preAGC[k] / H_chain(f_k)
                     │
                     ▼
          Vrms_original = √(Σ Vpeak_original[k]² / 2)  (Parseval)
```

### 计算步骤详解

```
Step 1: 读 ADC3 → Vd(mV) = adc3_val × 3300 / 4096
Step 2: G = ScopeAGC_ComputeGain(Vd)                // 二次拟合，见 §4
Step 3: Vpp_filtered = 3000.0f / G                  // AGC输入端总Vpp

Step 4: ADC1/2 4096点 → FFT (Hann窗 + 幅值修正)
Step 5: 峰值检测 → 候选频率列表
Step 6: 最低频有效峰 → f₁_raw → f₁ = round(f₁_raw/500) × 500
Step 7: 对 k=1,2,3,4 搜索 f_k = k×f₁ 附近 ±2bin → 最大峰
Step 8: Vpeak_adc[k] → ÷G → Vpeak_preAGC[k]
Step 9: φ_k = atan2(Im, Re) → 时域重建 → Vpp_preAGC
Step10: ÷H_chain(f_k) → Vpeak_original[k], Vpp_original
Step11: Vrms_original = √(Σ Vpeak_original[k]² / 2)
```

## 3. 加法器 + 滤波器链校准 H_chain(f)

### 数据集③ 实测数据（增益=输出/输入）

| Vin\f | 10k | 50k | 100k | 200k | 300k | 400k | 500k |
|-------|-----|-----|------|------|------|------|------|
| 50mV | 1.048 | 1.048 | 1.054 | 1.066 | 1.066 | 1.040 | 0.978 |
| 90mV | 1.040 | 1.040 | 1.046 | 1.058 | 1.058 | 1.031 | 0.967 |
| 130mV | 1.032 | 1.036 | 1.042 | 1.052 | 1.054 | 1.034 | 0.971 |
| 170mV | 1.035 | 1.038 | 1.041 | 1.053 | 1.053 | 1.029 | 0.971 |
| 210mV | 1.029 | 1.029 | 1.043 | 1.057 | 1.052 | 1.033 | 0.971 |
| 250mV | 1.032 | 1.032 | 1.040 | 1.056 | 1.056 | 1.032 | 0.964 |
| **平均** | 1.036 | 1.037 | 1.044 | 1.057 | 1.057 | 1.033 | **0.970** |

**当前策略**：用平均增益做分段线性插值
- 10k~300kHz: H ≈ 1.04~1.06（近似平坦）
- 300k~500kHz: 滚降到 0.97
- >500kHz: 保守外推 H ≈ 0.95

数据集 ①（加法器单独）和 ②（滤波器单独）作为辅助参考，验证链增益的正确性。

## 4. AGC 增益校准 G = f(Vd)

### 数据集④：42 个数据点

- 检波器输出 Vd：474 ~ 657 mV
- AGC 增益 G：11.4 ~ 61.3

### 最佳拟合：二次多项式 R² = 0.99935, MAE = 0.305

```
G(Vd) = 474.947 − 1.31554 × Vd + 0.0009279 × Vd²
```

### C 代码

```c
float ScopeAGC_ComputeGain(float vd_mV)
{
    if (vd_mV < 470.0f) vd_mV = 470.0f;
    if (vd_mV > 660.0f) vd_mV = 660.0f;
    return 474.947f - 1.31554f * vd_mV + 0.0009279f * vd_mV * vd_mV;
}
```

### 物理背景

AD603 增益控制是 dB-线性的（Gain(dB) = 40×Vg + offset），AGC 反馈环路产生非线性的 G(Vd) 关系，用二次多项式在标定范围内精确捕获。

## 5. 基频 500Hz 吸附

> 题目约束：多谐波信号的基频一定是 500Hz 的整数倍

```c
float raw_freq = parabola_interp_result;   // e.g. 10497.3 Hz
float n_float = raw_freq / 500.0f;          // = 20.9946
uint16_t N = (uint16_t)(n_float + 0.5f);    // = 21
float exact_freq = (float)N * 500.0f;        // = 10500 Hz ✓
```

- 频率精度：**0 误差**（比赛指标 ≤1kHz，远超要求）
- 谐波位置精确：f_k = k × N × 500，在 ±2 bin 窗口内精确搜索
- 周期截取精准：T = 1/f₁ 精确可算

## 7. 干扰处理策略

| 要求 | u_J 接入 | LPF | 软件处理 |
|------|---------|-----|---------|
| 要求1 (u_a) | ❌ 模拟开关断开 | 正常工作 | 无干扰，直接分析 |
| 要求2 (u_b) | ❌ 模拟开关断开 | 正常工作 | 无干扰，直接分析 |
| 要求3 (u_b+u_J) | ✅ GPIO 闭合模拟开关 | 700kHz 衰减 ≥1MHz | FFT 识别非整数倍峰 → 排除 |

干扰防御双层：
1. **硬件层**：LPF 700kHz 对 ≥1MHz 干扰衰减
2. **软件层**：FFT 整数倍验证 + 幅值匹配（复用 v3 三层防御逻辑）
