## 一、完整信号链路

```
                              ┌──▶ [检波器] → [跟随器] → ADC2
                              │      (读 Vpp 硬件真值: 直流)
                              │
[多谐波 u_b] ─┬─▶ [加法器] ──┤
  50~250mVpp  │              │
  双极性      │              └──▶ [AD603 AGC] → [+1.6V偏置] → ADC1
              │                    增益到3.2Vpp     0~3.2V      2MSPS/4096pt
[干扰 u_J]  ─┘                    双极性          单极性       (采样+FFT)
  200mVpp
  ≥1MHz, 双极性
```

| 环节 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 信号源 | — | u_b + u_J，两路双极性 | 多谐波 50~250mVpp + 干扰 200mVpp |
| 加法器 | u_b, u_J | 总信号（双极性，无偏置） | Vpp 约 206~450mVpp（取决于相位关系） |
| AGC | 总信号 | 增益到 3.2Vpp（双极性） | 自动调节增益，输出幅度恒定 |
| +1.6V 偏置 | AGC 输出 | 0~3.2V 单极性 | 适配 ADC 0~3.3V 输入范围 |
| ADC1 | 偏置后信号 | 4096 点 @2MSPS | TIM2 触发，DMA 搬运 |
| 检波器 | 加法器后、AGC 前 | 直流电压 ∝ Vpp | 包络检波，输出 = k × 总信号 Vpp |
| 跟随器 | 检波器输出 | 低阻抗直流 | 阻抗隔离，驱动 ADC2 |
| ADC2 | 跟随器输出 | 直流电压值 | 与 ADC1 同步触发 |

## 二、各参数计算来源

### 核心原则

**ADC1 的时域数据混了有用信号 + 干扰 + 直流偏置，不能直接算 u_b 的 Vpp/Vrms。必须先通过 FFT 把 u_b 和 u_J 分开。**

### 参数来源表

| 参数 | 数据来源 | 计算方法 | 备注 |
|------|---------|---------|------|
| **Vdc** | ADC1 时域 | Σ v[n] / N | 应 ≈ 1.6V（偏置电压） |
| **Vpp_total** | ADC1 时域 | max − min | 含干扰+偏置，**不是 u_b 的 Vpp** |
| **Vrms_total** | ADC1 时域 | √(Σ(v[n]−Vdc)²/N) | 含干扰，**不是 u_b 的 Vrms** |
| **基频 f₁** | ADC1 → FFT | 最低频率的有效谱线峰 | 抛物线插值修正 |
| **基波幅值 A₁** | ADC1 → FFT | f₁ 位置的归一化幅度 | 单位 Vpeak |
| **谐波频率 f_k** | ADC1 → FFT | f₁ × k 附近 ±2 bin 搜索最大峰 | k = 2, 3, 4, … |
| **谐波幅值 A_k** | ADC1 → FFT | 谐波位置的归一化幅度 | 单位 Vpeak |
| **u_b 的 Vrms** | ADC1 → FFT → Parseval | √(Σ A_k²/2) | 从频谱分量反推，不含干扰 |
| **u_b 的 Vpp** | ADC1 → FFT → 时域重建 | 用 A_k, f_k, φ_k 重建 u_b[n] → max−min | 需提取相位 |
| **Vpp_input_total** | ADC2 直流 | ADC2_val × 标定系数 | 检波器硬件真值（AGC 前） |
| **AGC 增益 G** | ADC2 + 已知条件 | G = 3.2V / Vpp_input_total | 间接推算 |
| **干扰预期幅值(ADC域)** | ADC2 + 已知条件 | 0.1V × G | 干扰 200mVpp → 100mV peak → ×G |

### 时域 vs 频域分工

```
═══════════════════════════════════════
  时域 (ADC1 原始数据, 无 FFT)
═══════════════════════════════════════
  • Vdc            — 简单求平均
  • Vpp_total      — max−min (仅用于 Parseval 校核)
  • Vrms_total     — RMS 积分 (仅用于 Parseval 校核)

═══════════════════════════════════════
  频域 (ADC1 → FFT → 峰值检测)
═══════════════════════════════════════
  • f₁             — 最低频有效峰
  • A₁             — 基波幅值 (Vpeak)
  • f_k, A_k       — 谐波频率和幅值
  • 干扰标识       — 不满足整数倍的孤立峰

═══════════════════════════════════════
  频域 → 反推时域 (从频谱重建)
═══════════════════════════════════════
  • u_b 的 Vrms    — Parseval 定理
  • u_b 的 Vpp     — 重建 u_b 波形 → max−min

═══════════════════════════════════════
  ADC2 直流 (检波器)
═══════════════════════════════════════
  • Vpp_input_total — 总信号的硬件 Vpp 真值
  • G (AGC增益)     — 间接推算
  • 干扰预期幅值    — 用于交叉验证频谱中的可疑谱线
```

## 三、关键公式

### 3.1 从 FFT 频谱分量反推 u_b 的 Vrms (Parseval 定理)

```
Vrms² = (1/N) × Σ v[n]² = Σ (mag[k]²) / 2   (k ≥ 1, AC 分量)

对于 u_b 的频谱分量:
  Vrms_u_b = √( A₁²/2 + A₂²/2 + A₃²/2 + ... )

其中:
  A₁ = 基波的 Vpeak 幅度 (FFT bin 的归一化值 × Vref/ADCmax)
  A₂, A₃, ... = 各谐波的 Vpeak 幅度
```

### 3.2 从 FFT 频谱分量重建 u_b 的 Vpp

```
① 从 FFT 提取每个分量的: f_k, A_k, φ_k（相位从复数频谱获取）
② 重建时域:
     u_b[n] = Σ A_k × sin(2π × f_k × n/Fs + φ_k)
     对所有 n = 0, 1, ..., N-1

③ Vpp_u_b = max(u_b) − min(u_b)
```

### 3.3 ADC2 检波器

```
Vpp_input_total = ADC2_val × K_calib
  其中 K_calib = 1.0 (检波器不放大，输出直流电压 = 输入信号 Vpp)

AGC 增益: G = 3.2V / Vpp_input_total

干扰预期幅值 (ADC 域):
  A_J_expected = 0.1V × G  (单位: Vpeak)
  其中 0.1V = 200mVpp / 2
```

### 3.4 交叉验证

```
校验 1 (Parseval 一致性):
  | Vrms_total² − Vrms_u_b² − Vrms_J² | < ε₁
  其中 Vrms_J = A_J_expected / √2 (预期干扰有效值)

校验 2 (Vpp 一致性):
  | Vpp_u_b (重建) + 0.2V − Vpp_input_total (ADC2) | < ε₂
  其中 0.2V = 干扰 200mVpp（未增益，因为 ADC2 在 AGC 之前）

校验 3 (谐波幅值检查):
  对每个识别出的谐波 A_k:
    如果 |A_k − A_J_expected| < ε₃ → 该"谐波"可疑，可能是干扰冒充
```

## 四、干扰排除：三层防御

### 问题描述

干扰 u_J ≥ 1MHz，Nyquist = 1MHz (Fs=2MSPS ÷ 2)，干扰必然混叠。

```
混叠公式: f_alias = |2MHz − f_J|

f_J = 1.0~1.5MHz → f_alias = 1.0~0.5MHz (在信号带之上, 500k~1MHz)
f_J = 1.5~2.0MHz → f_alias = 0.5~0MHz   (部分落入信号带 10k~500kHz)
```

**最坏情况**：测试方故意选择 f_J 使得 f_alias = k × f₁（恰好等于某次谐波频率）。此时仅靠整数倍验证会误判。

### 层 ①：整数倍关系验证（主防线）

```
算法:
  1. 在频谱中找所有峰值
  2. 最低频率的有效峰 → 候选基频 f₁
  3. 对每个峰值检查: 是否存在整数 k 使得 f_peak ≈ k × f₁
     → 是: 标记为该次谐波
     → 否: 标记为干扰

覆盖场景: 混叠干扰频率 ≠ k × f₁（绝大多数情况）
失效条件: f_alias = k × f₁（测试方刻意设置）
```

### 层 ②：ADC2 期望幅值对比（辅助防线）

```
算法:
  1. 从 ADC2 读取 Vpp_input_total
  2. 推算 AGC 增益 G = 3.2 / Vpp_input_total
  3. 计算干扰在 ADC 域的预期幅值: A_J_expected = 0.1V × G
  4. 对每个"谐波"检查:
     如果 A_k ≈ A_J_expected → 可疑（可能是干扰冒充的）

覆盖场景: 干扰恰好落在谐波位置，但幅值不匹配
失效条件: A_k 恰好 ≈ A_J_expected（需测试方同时控制频率和增益）
```

### 层 ③：Parseval + ADC2 交叉校核（兜底）

```
算法:
  1. 从 FFT 计算 Vrms_u_b (Parseval) 和 Vpp_u_b (时域重建)
  2. 从 ADC2 读取 Vpp_input_total
  3. 从 ADC1 时域计算 Vrms_total

  校验:
    如果 Vpp_u_b + 0.2V ≈ Vpp_input_total → 能量守恒，结果可信
    如果偏差大 → 存在未正确分配的频谱分量（干扰可能被当成了谐波）

覆盖场景: 层①②都失效
失效条件: 干扰混叠恰好 = k×f₁ 且 幅值恰好 = A_k（极低概率）
```

### 防御覆盖矩阵

| 场景 | 层① | 层② | 层③ | 结果 |
|------|-----|-----|-----|------|
| 孤峰干扰（不在谐波位） | ✅ 排除 | — | — | 干扰被正确排除 |
| 干扰在谐波位，幅值不匹配 | ❌ 误判 | ✅ 发现 | — | 幅值差异告警 |
| 干扰在谐波位，幅值恰好匹配 | ❌ 误判 | ❌ 漏过 | 🟡 偏差告警 | 标记为"低置信度" |

> **第三层失效是极小概率事件**——要求测试方同时精确控制干扰频率（使之混叠后恰好 = k×f₁）和 AGC 增益（使干扰幅值恰好 = 该谐波的预期幅值）。在真实测试条件下几乎不可能刻意做到。

### 各模块改动概要

| 模块 | 现状 | 需要改为 |
|------|------|---------|
| `scope_adc.c` | 单 ADC1, 单 DMA 缓冲 | 双 ADC (ADC1+ADC2) 同步, TIM2 同时触发, 两个 DMA 缓冲 |
| `scope_fft.h` | `ScopeResult` 含 Vpp/Vrms/Vdc 等 | 增加 `vpp_envelope`(ADC2), `confidence`(置信度), `interference_detected`(干扰标记) |
| `scope_fft.c` | Vpp/Vrms 从时域直接算 | Vpp/Vrms 改为从 FFT 频谱分量反推; 增加相位提取; 增加时域重建函数; 内嵌三层防御+交叉验证 |
| ~~scope_verify.c~~ | — | 已合并入 scope_fft.c，不独立成模块 |

### 数据流

```
main() 主循环:

  while (1) {
      等待双 ADC DMA 完成 (ADC1: 4096pt, ADC2: 1pt 或平均)

      ┌─ Path 1: ADC1 数据 ─────────────────────┐
      │  ScopeFFT_Analyze(raw_buf1)              │
      │    → fft_mag[]                           │
      │    → 峰值检测 → f₁, f_k, A_k             │
      │    → 干扰识别 (整数倍验证)                │
      │    → Parseval → Vrms_u_b                 │
      │    → 相位提取 → 时域重建 → Vpp_u_b       │
      └──────────────────────────────────────────┘

      ┌─ Path 2: ADC2 数据 ─────────────────────┐
      │  ScopeADC_ReadEnvelope(raw_buf2)         │
      │    → Vpp_input_total (检波器硬件值)       │
      │    → G = 3.2 / Vpp_input_total           │
      │    → A_J_expected = 0.1 × G              │
      └──────────────────────────────────────────┘

      ┌─ Path 3: 交叉验证 ──────────────────────┐
      │  ScopeVerify_Check(result_fft, result_adc2)
      │    → 校验 1: Parseval 一致性              │
      │    → 校验 2: Vpp 一致性                   │
      │    → 校验 3: 谐波幅值 vs 干扰预期          │
      │    → 输出: confidence (高/中/低)           │
      └──────────────────────────────────────────┘

      串口输出 / 屏幕显示结果
      重启 DMA 准备下一轮
  }
```

| | 之前 (scope_fft.c v1) | 现在 (要求3方案) |
