# 信号处理计算方案辩论总结

> 2026-08-01，关于"FFT 幅值反推是否需要穷举法"的完整讨论

---

## 1. 辩论核心：频域反推 vs 时域穷举

### 用户最初方案（穷举法）

```
认为 FFT 只能给出基波/谐波的"相对比例"
→ 不知道绝对峰峰值
→ 需要穷举所有分量幅值组合
→ 时域合成波形, 匹配"滤波后总信号 Vpp"
→ 误差最小的组合 = 真实值
```

### 实际方案（频域独立反推）

```
FFT 给出每个频率分量的绝对幅值（Parseval 定理）
→ 每个谐波独立除以 H_chain(k·f₁) / G
→ 得到每个谐波的原始峰峰值
→ 不需要穷举, 不需要时域合成
```

---

## 2. 关键结论

### ✅ FFT 的 bin 幅值是**绝对电压值**，不是相对比例

```
DFT 正交分解性质:
  v[n] = Σ A_k · sin(2π·k·n/N + φ_k)
  FFT →
    |X[k]| = A_k · N/4      (Hann 窗, AC bin)

Parseval 定理: |X[k]| 只依赖 A_k,
与其他谐波相位 φ_j 完全无关
```

`|X[k]|` 就是第 k 次谐波在 ADC 输入端的**绝对峰值电压（mV）**。不存在"丢失维度信息"——N 点 FFT 的 N 个独立 bin 完整保留了维度信息。

### ✅ 相位偏移由 LPF 引起，但不影响幅值

LPF 传递函数 `H(jω) = |H|·e^{jφ}` 中：
- `|H(jω)|` → `H_chain(f)` 修正幅值
- `φ(f)` → `φ_LPF(f)` 修正相位

两者独立，不需要联合穷举。相位修正用于验证链路正确性（信号源相位=0 → 修正后应≈0）。

### 🟡 时域 Vpp 受相位影响——但 FFT 绕过了这个问题

```
v1 = A₁sin(ωt) + A₂sin(2ωt)      φ₂=0  → 时域Vpp = V₁
v2 = A₁sin(ωt) + A₂sin(2ωt+90°)  φ₂=90°→ 时域Vpp = V₂ ≠ V₁

但 FFT |X[2ω]| 完全一样 = A₂/2
```

如果只有一个峰值检波器读"总 Vpp"（标量），才需要穷举。有了 FFT 不需要。

## 3. 发现的问题：偏置电路校准缺口

### 问题

```
校准:  AGC输入 → [AD603] → AGC输出 ─── G=f(Vd) 在这里定义

代码:  V_adc / G → 反推AGC输入
       ↑ 隐含假设 V_adc = V_AGC输出 (偏置电路无衰减)

实际:  AGC输出 → [直流偏置] → ADC输入
       ↑ 偏置电路有衰减, V_adc < V_AGC输出
```

如果 ADC 输入端实际只有 AGC 输出的 90%，那么 `V_adc/G` 会低估 AGC 输入 ~10%。

### 用户确认

> "AD603-AGC 模块增益后的信号峰峰值为 3.01V，经过偏置电路会有衰减，但忽略掉"

当前代码**忽略了这个衰减**，这是一个已知近似。

### 修复方案

| | 方案 A（重测校准） | 方案 B（单独测 α） |
|---|---|---|
| 做法 | 测 AGC输入 → ADC输入端（含偏置），拟合 G_effective=f(Vd) | 测 α=V_adc/V_AGC输出，代码乘 α |
| 代码改动 | 零 | 需改 scope_fft.c |
| 精度 | 偏置衰减被拟合方程吸收 | α 和 G 各自拟合误差叠加 |
| **推荐** | ✅ | ❌ |

## 4. 穷举法何时才需要？

### 不需要穷举 ✅

```
多谐波信号 → FFT → 频域已拆分各分量 → 独立修正
```

因为 FFT 做了正交分解，信号链的 H_chain 和 G 都是已知函数。

### 需要穷举 ❌（本系统不适用）

```
多谐波信号 → 一个峰值检波器 → 只能读"总Vpp" → 丢失了频谱维度
                                     ↑ 这种情况才需要穷举
```
