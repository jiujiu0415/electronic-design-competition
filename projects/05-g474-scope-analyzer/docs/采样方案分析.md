# 采样方案分析：2MSPS + 4096 FFT

> 讨论时间：2026-07-29
> 结论：2MSPS + 4096 FFT 可行，要求1/2 无混叠风险，要求3 基频检测不受干扰混叠影响

---

## 一、参数推导

### 频率分辨率约束

题目要求频率分辨率 ≤ 500Hz：

```
Fs / N ≤ 500Hz

2,000,000 / 4096 = 488 Hz ✅ (余量 12Hz)
```

### 采样率速度约束

题目要求每项测量 ≤ 2 秒：

```
DMA 采集 4096 点: 4096 / 2M = 2.048 ms
FFT (arm_rfft_fast_f32): ~0.5 ms (M4F @170MHz)
峰值检测 + 参数计算: < 1 ms
串口输出: < 10 ms
─────────────────────────────
总耗时 < 20 ms << 2 秒 ✅
```

### ADC 物理能力

```
ADC 时钟: SYSCLK/4 = 42.5 MHz (同步模式, < 60MHz max)
单次转换: (2.5 + 12.5) / 42.5M = 0.353 μs
最大采样率: 1 / 0.353μs ≈ 2.83 MSPS > 2.0 MSPS ✅
```

### G474 TIM2 精度

```
TIM2 时钟 = APB1 = 170 MHz
PSC = 0, ARR = 84
Fs = 170M / (0+1) / (84+1) = 2.0 MHz (精确)
```

## 二、要求 1/2：无干扰，完全无混叠

| 要求 | 频率范围 | Nyquist (1MHz) 覆盖？ | 混叠风险 |
|------|---------|----------------------|---------|
| 要求1 | 10k~200kHz | ✅ 信号远小于 1MHz | **无** |
| 要求2 | 10k~500kHz | ✅ 信号 ≤ 1MHz | **无** |

信号最高 500kHz < Nyquist 1MHz，符合采样定理，时域波形和频谱均准确。

---

## 三、要求 3：1MHz+ 干扰的混叠分析

### 核心问题

```
采样率 Fs = 2MSPS → Nyquist = 1MHz

干扰 f_J ≥ 1MHz 超过了 Nyquist 频率
→ 会发生混叠（aliasing）
```

### 不同干扰频率的混叠结果

| 干扰频率 f_J | 混叠到 | 是否落入 10k~500kHz 信号带？ | 影响基频检测？ |
|-------------|--------|---------------------------|-------------|
| 1.0 MHz | 1.0 MHz (Nyquist 边界) | ❌ 衰减极大 | 否 |
| 1.1 MHz | 0.9 MHz | ❌ 在信号带之上 | 否 |
| 1.2 MHz | 0.8 MHz | ❌ 在信号带之上 | 否 |
| 1.5 MHz | 0.5 MHz | 🟡 恰好在边界 | 否（基频远低于边界） |
| 1.8 MHz | 0.2 MHz | ✅ **落入信号带** | 🟡 多一根假谱线 |
| 2.0 MHz | 0 Hz (DC) | ❌ 直流附近 | 否 |

```
混叠公式: f_alias = |Fs - f_J| = |2MHz - f_J|

f_J = 1.0~1.5MHz → f_alias = 1.0~0.5MHz (在信号带之上)
f_J = 1.5~2.0MHz → f_alias = 0.5~0MHz (⚠️ 部分落入信号带)
```

### 为什么基频检测依然可靠

即使混叠干扰落入信号带，也不影响基频识别：

**信号结构已知** — 题目说明：
> uₐ 或 u_b 是由基波分量与 1 个或者 2 个谐波分量组合而成的周期信号

这意味着频谱中有且仅有 **2~3 根谱线**，且它们满足 **整数倍关系**：

```
真实信号:
  基频 f₁ ── 幅度 A₁
  谐波 k₁·f₁ ── 幅度 A_{k₁}
  谐波 k₂·f₁ ── 幅度 A_{k₂}

干扰混叠:
  一根孤立的谱线，不满足任何整数倍关系
  → 基频识别算法直接忽略
```

**基频识别策略**：
1. 在频谱中找到所有峰值（幅度超过噪声阈值）
2. 最低频率的峰 = 候选基频 f₁
3. 检查是否存在 f₁ 的整数倍位置的峰 → 确认这是真的基频
4. 不满足整数倍关系的峰 → 排除（是噪声或混叠干扰）

## 四、为什么暂不加硬件滤波

| 理由 | 说明 |
|------|------|
| 要求1/2 不需要 | 无干扰信号，2MSPS 完全满足采样定理 |
| 要求3 基频不受影响 | 混叠干扰不破坏基频+谐波的整数倍特征 |
| 先跑通再优化 | 软件框架跑通后，实测一个 1.8MHz 干扰看实际表现 |
| 如果真需要 | 一个 RC 低通（1 电阻 + 1 电容）就能大幅衰减 |
| **最大优势** | 先用纯软件验证全部逻辑，硬件只加最少的东西 |

> **核心洞察**：周期信号测量分析的基频检测不是"从噪声里挖信号"，而是"从一堆谱线里找到符合整数倍关系的那一组"。混叠不会伪造出整数倍关系，所以不改变基频识别结果。

## 五、选型决策记录

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 采样率 | **2.0 MSPS** | 覆盖 500kHz 信号，Nyquist 余量充足 |
| FFT 点数 | **4096** | 频率分辨率 488Hz，满足 500Hz 要求 |
| ADC 触发 | **TIM2 TRGO** | 精确控制采样间隔，项目04已验证 |
| DMA 模式 | **Circular** | 持续采集不中断 |
| ADC 时钟 | **同步 /4 (42.5MHz)** | 避免跨时钟域抖动 |
| 抗混叠滤波 | **暂不加** | 要求1/2 无干扰，要求3 基频不受混叠影响 |
| 前端放大 | **暂不加** | 先用 1Vpp 信号验证软件逻辑 |
