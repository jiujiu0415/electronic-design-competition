# 裸芯片 G474RET6 硬件注意

> 你不是用 NUCLEO 板，是裸 STM32G474RET6。以下是从 NUCLEO → 裸板的关键变化。

---

## 一、最小系统检查清单

裸芯片要跑起来，至少保证这 5 项：

| 序号 | 项目 | 要求 | 不满足后果 |
|------|------|------|-----------|
| 1 | VDD | 3.3V，每个 VDD 脚加 100nF+10μF 去耦电容 | 芯片不工作 |
| 2 | VDDA | 3.3V，必须接（即使不用 ADC 也要接） | ADC 采出来全是乱的 |
| 3 | NRST | 10kΩ 上拉到 3.3V | **无法烧录**（一直处于复位状态） |
| 4 | BOOT0 | 10kΩ 下拉到 GND | 从 SRAM/System Memory 启动，不从 Flash 跑 |
| 5 | SWD | PA13(SWDIO) + PA14(SWCLK) 引出排针 | **无法烧录/调试** |

---

## 二、CubeMX 配置与 NUCLEO 的差异

| 配置页 | NUCLEO 设置 | 裸板设置 |
|--------|------------|---------|
| RCC → HSE | BYPASS (来自ST-LINK MCO 8MHz) | **Disable** |
| RCC → HSI | 可能关 | **必须开 (16MHz)** |
| Clock Config → PLL Source | HSE | **HSI** |
| SYS → Debug | Serial Wire | **Serial Wire** (必须手动选) |
| 串口 | ST-LINK VCP | **外接 USB-TTL 模块** |

---

## 三、HSI 时钟链计算

```
HSI (16MHz)
  ↓ /PLLM = /4
4MHz
  ↓ ×PLLN = ×85
340MHz VCO
  ↓ /PLLR = /2
170MHz SYSCLK ✅
```

和 NUCLEO 的唯一区别：PLL 的输入从 HSE(8MHz) 变成 HSI(16MHz)，PLLM 从 /2 改为 /4，其余不变。

---

## 四、外接工具接线

### ST-LINK/V3 调试+烧录（必须）

```
ST-LINK          你的板子
SWDIO   ──────── PA13
SWCLK   ──────── PA14
GND     ──────── GND
3.3V    ───/──  不接（板子自己供电，如果板子没电则接）
```

### USB-TTL 串口（调试打印）

```
USB-TTL           你的板子
RX     ──────── PA2  (USART2_TX)
TX     ──────── PA3  (USART2_RX, 可选)
GND    ──────── GND
```

## 五、5V→3.3V 供电方案

题目要求 5V 供电，你需要一个 LDO 降压到 3.3V：

| 元件 | 推荐 | 原因 |
|------|------|------|
| LDO | AMS1117-3.3 | 便宜、常见、1A 够用 |
| 输入电容 | 10μF (5V 侧) | 防电源抖动 |
| 输出电容 | 10μF + 100nF (3.3V 侧) | 滤波+去耦 |

如果后续加了运放电路需要 ±5V 或更高电压，可能需要额外加 DC-DC 升压模块（单独处理）。
