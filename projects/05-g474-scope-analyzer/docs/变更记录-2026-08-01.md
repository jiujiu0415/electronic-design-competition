## #4 — 基频检测: 纯正弦波误选噪声峰

| 项 | 值 |
|----|-----|
| Commit | `45c7edd` |
| 时间 | 13:44 |
| 回退 | `git revert 45c7edd` |

### 改动文件

| 文件 | 改动 |
|------|------|
| `Core/Src/scope_fft.c:321-360` | 谐波匹配前增加最强峰幅值预扫描 + 弱峰过滤 |

### 改动逻辑

```
问题: 100kHz纯正弦波, 19次测量有7次(37%)误选10k-22kHz噪声峰
      表现: f1=14000Hz, Fund=0.0mVpk, 频率检测完全错误

根因:
  谐波匹配算法: 每个候选峰统计整数倍处的"谐波"匹配数
  100kHz信号峰 → 0个匹配 (纯正弦波, 无谐波)
  14kHz噪声峰   → 1个匹配 (噪声在28kHz处偶然对齐)
  1 > 0 → 噪声峰胜出

修复 (scope_fft.c, 阶段4):
  谐波匹配前先扫描有效频率范围内最强峰幅值
  幅值<最强峰20%的候选直接跳过, 不参与匹配
  → 噪声峰(<5%最强峰)被过滤, 信号峰(100%)正常参与
  
  纯正弦波: 信号峰=最强峰 → 100%正确
  多谐波信号: 基波≥20%最强峰 → 正常匹配 (方波基波~30%H3, 安全)
```

| `Core/Inc/scope_calib.h` | 更新 Vd 范围 [533,722], G 范围 [11.4,63.5] |

### 改动逻辑

```
修复: 谐波搜索频率基准
  旧: target_freq = order * r.f1_hz  (吸附后的500Hz网格频率)
  新: target_freq = order * r.f1_raw_hz  (raw频率)
  
  例: raw=99750Hz→snap到100000Hz, H8搜索中心漂移2000Hz(4bin)→超出±2bin窗口
  影响: 信号偏离500Hz网格时高次谐波可能漏检

AGC 含偏置电路:
  旧校准: G = V_AGC_output / V_AGC_input (不含偏置)
  新校准: G_eff = V_ADC_input / V_AGC_input (含偏置, ~0.1%衰减可忽略)
  解决了之前1.63x幅度偏差问题
```
