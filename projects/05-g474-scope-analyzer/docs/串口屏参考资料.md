## 2. 引脚连接 (屏 ↔ STM32G474)

```
屏幕端          STM32G474
───────────────────────────
VCC (5V)   →   5V 电源
GND        →   GND
TX         →   PA3 (USART2_RX)   ← 屏发→MCU收
RX         →   PA2 (USART2_TX)   ← MCU发→屏收
```

> 屏幕 TX 接 MCU RX，屏幕 RX 接 MCU TX。交叉连接。
> 屏幕 5V 供电，TTL 电平（3.3V/5V 兼容）。

## 3. TJC 通信协议速查

### 3.1 基本规则

- 所有指令以 **`0xFF 0xFF 0xFF`** (3字节) 结尾
- 默认波特率 115200, 8N1
- 数字组件 `n`，文本组件 `t`，按钮 `b`，波形 `s`，进度条 `j`

### 3.2 常用指令 (MCU → 屏幕)

| 指令 | 语法示例 | 说明 |
|------|---------|------|
| 数字赋值 | `n0.val=10500` | 设置数字组件 |
| 文本赋值 | `t0.txt="Hello"` | 文本需带双引号 |
| 切换页面 | `page 1` | 切换到页面1 |
| 波形加点 | `add 0,x,y` | s0通道,坐标(x,y) |
| 波形批量加点 | `addt 0,N,v1,v2,...` | 批量添加N个Y值, x自动递增 |
| 清除波形 | `cle 0,0` | 清除s0通道所有数据 |
| 显示/隐藏 | `vis t0,1` | 1=可见, 0=隐藏 |
| 模拟按钮 | `click b0,1` | 1=按下, 0=释放 |
| 获取属性 | `get n0.val` | 屏幕返回当前值 |
| 改变波特率 | `baud=921600` | 修改后屏幕会用新波特率 |
| 设置返回等级 | `bkcmd=3` | 已弃用, 改用 printh 方案 |
| 刷新页面 | `ref` | 重绘当前页面 |
| 发送页号 | `sendme` | 屏幕返回当前页面ID |
| 清屏 | `cls 0` | 0=当前页背景色清屏 |
| 画线 | `line x1,y1,x2,y2,color` | GUI绘图 |
| 填充矩形 | `fill x1,y1,w,h,color` | GUI绘图 |
| 画圆 | `cir x,y,r,color` | GUI绘图 |

### 3.3 触摸事件 (屏幕 → MCU) — printh 方案

**每个按钮写按下事件脚本：**

```
printh 55 <page_id> <component_id> <event_type>
```

屏幕自动在末尾追加 `FF FF FF`，MCU 收到 7 字节帧：

```
0x55 | page_id | component_id | event_type | 0xFF 0xFF 0xFF

event_type:
  0x01 = 按下 (PRESS)
  0x00 = 释放 (RELEASE)
```

**按钮脚本：**

| 按钮 | 位置 | printh 脚本 |
|------|------|------------|
| b0 | Page 0 周期切换 | `printh 55 00 00 01` |
| b1 | Page 0 →频谱 | `printh 55 00 01 01` |
| b0 | Page 1 →波形 | `printh 55 01 00 01` |

> 不需要 `bkcmd=3`。printh 方案不依赖屏幕自动返回机制，更可控。

## 4. 波形组件 `s` 关键知识

- 支持多通道 (ch0, ch1, ch2...)
- `add channel,x,y` — 加单个点
- `addt channel,N,y0,y1,...` — 批量加N个Y值 (速度快10倍+)
- `cle channel,color` — 清除通道，color=背景色
- 清除后 x 指针自动复位到 0
- 属性：`dis` (通道数), `dir` (方向), `grid` (网格)

### 波形数据优化建议

- 横屏 800×480，波形区域 s0=700px 宽，频谱 s1=550px 宽
- 4096 采样点 → 下采样 700 对 (min+max) = 1400 点 → addt 批量发送
- FFT 2049 bins → 下采样 600 点 → addt 批量发送
- 优先用 `addt` 批量发送，单次发送比分条快 10 倍+
- 每帧数据量: 波形 ≈1400×5=7000 字节, 频谱 ≈550×5=2750 字节
- 115200 bps 下: 波形 ≈0.6s, 频谱 ≈0.24s — 2 秒更新周期够用

## 5. STM32 HAL 库集成要点

### 5.1 UART 初始化

```c
// USART2, 115200, 8N1
// CubeMX → NVIC → 勾选 USART2 global interrupt (RX用)
// CubeMX → USART2 Mode → Asynchronous
```

### 5.2 发送 (参考 TJC 示例)

```c
// 方式1: printf风格 (标准库版)
TJCPrintf("n0.val=%d", value);  // 自动加 FF FF FF

// 方式2: 字符串发送 (HAL版)
tjc_send_string("n0.val=100");  // 自动加 FF FF FF

// 方式3: 组件专用
tjc_send_val("n0", "val", 100);    // n0.val=100
tjc_send_txt("t0", "txt", "ABC");  // t0.txt="ABC"

// 方式4: 原始字节
TJC_SendData(buf, len);  // 不自动加结束符
```

### 5.3 接收 (环形缓冲区)

```c
// 500字节环形缓冲区 (参考 tjc_usart_hmi.c)
// HAL_UART_RxCpltCallback → writeRingBuff(data)
// 主循环轮询检查 → 匹配 0x55 帧头 → 解析 printh 事件
```

### 5.4 接收帧解析

```c
while (ring_buf_len >= 7) {
    if (buf[0]==0x55 && buf[4]==0xFF && buf[5]==0xFF && buf[6]==0xFF) {
        uint8_t page   = buf[1];
        uint8_t comp   = buf[2];
        uint8_t event  = buf[3];  // 0x01=按下, 0x00=释放
        // 处理事件...
        ring_buf_delete(7);
    } else {
        ring_buf_delete(1);  // 丢1字节重新对齐
    }
}
```

### 6.1 页面规划

| 页面 | 内容 | 主要组件 |
|------|------|---------|
| Page 0 | 时域波形 + 参数 (赛题1-(2)) | s0(波形 700×280), n0(Vpp), n1(Vrms), n2(f₁), b0(周期切换), b1(→频谱页), t4(标签) |
| Page 1 | 频谱定性 + 频率分量幅值 (赛题1-(3)(4)) | s1(频谱 600×320), t9~t17(文本,动态显示基波+谐波频率/幅值), b0(→波形页) |

### 6.2 组件 objname 对照表

> ⚠️ 拖入组件后软件自动编号 `1`, `2`, `3`...，需在属性面板将 **`objname`** 改为下表值。
> MCU 指令中引用的就是 objname（如 `n0.val=150.2` 中的 `n0`）。

| 页面 | objname | 类型 | 显示内容 | 说明 |
|------|-----|------|---------|------|
| 0 | s0 | 波形 | 时域波形 (ch0) | 700×280 |
| 0 | n0 | 数字 | Vpp (mV) | `%0.1f` 赛题 1-(2) |
| 0 | n1 | 数字 | Vrms (mV) | `%0.1f` 赛题 1-(2) |
| 0 | n2 | 数字 | f₁ (Hz) | `%0.1f` 赛题 1-(2) |
| 0 | b0 | 按钮 | 切换 1/3 周期 | 触摸返回 |
| 0 | b1 | 按钮 | → 频谱页 | 触摸返回 |
| 0 | t4 | 文本 | "1周期"/"3周期" | MCU 更新 |
| 1 | s1 | 波形 | 频谱定性 | 600×320 |
| 1 | t9~t11 | 文本 | 基波 H1, 频率, 幅值 | 始终显示 |
| 1 | t12~t14 | 文本 | 谐波1 (次数动态), 频率, 幅值 | 无则 "—" |
| 1 | t15~t17 | 文本 | 谐波2 (次数动态), 频率, 幅值 | 无则 "—" |
| 1 | b0 | 按钮 | ← 返回波形页 | 触摸返回 |

> n3 (基波 Vpeak) 已移除 — 赛题不要求单独显示。谐波用文本组件动态显示实际检出的谐波次数和幅值。

> MCU 通过 `tjc_set_val_float()` 直接发送浮点字面值 (如 `n0.val=150.2`), 屏幕 `format=%0.1f` 显示 1 位小数。精度 ±0.1mV 满足赛题 ≤5mV 误差要求。

## 7. 注意事项

### 🟡 波特率考虑

- 默认 115200：稳定但传输慢
- 大量波形数据 (400+ 点 × 多次更新) 可能 >1秒
- 如需提速：`baud=921600` 修改屏幕波特率 (CubeMX 同步改为 921600)

### 🟡 printf 重定向冲突

原工程 USART2 用于 printf 调试。整合时：
- TJC 模式下 USART2 全部用于屏幕通信
- 如需调试：保留 SWD 断点调试或加一个软件串口 (SWO)
- 或加编译开关 `SCOPE_DISPLAY_USE_TJC` 在调试模式和屏模式间切换

### 🟢 协议兼容性好

TJC 全线产品（不论尺寸/分辨率）使用相同指令集。
→ 现在 4.8" 写好的通信代码，换大屏后无需修改。
→ GUI 工程需要重新设计（分辨率不同），但通信协议不变。
