## 三、分析结论

### 1. Vin 依赖可忽略

Vin 方向 std/mean = 0.47%。对 50mV 信号误差 ≈ 50×0.0047 = **0.24mV**，远小于 5mV 要求。

**→ 仅用频率依赖 H_chain(f) 即可。**

### 2. 加法器 ≠ 加法器×滤波器

H_chain / (H_add × H_filt) = 0.9607 ± 0.0073

加法器和滤波器级联后存在阻抗匹配效应，独立相乘会系统性高估 4%。

**→ 必须用数据集③的联合测量值。**

### 3. 频响非简单 LPF

200-300kHz 处有轻微 peaking (H=1.057)，非单调滚降。用 LPF 物理模型 RMSE=0.012 > 7点查表 RMSE=0.005。

**→ 推荐 7 点分段线性插值。**

## 五、最终实现：自然三次样条

### 公式

```
fn = (freq_hz - 10000) / 490000        归一化到 [0, 1]
S_i(fn) = a_i + b_i·dx + c_i·dx² + d_i·dx³   其中 dx = fn - fn_i
```
