## 二、拟合对比

### 为什么不是 G = k/Vd？

```
G × Vd 范围: [7466, 29080]，差了 4 倍 → 不是常数
简单反比模型 R² = 0.30，不可用
```

物理原因：AD603 增益是 dB-线性的 (Gain_dB = 40×Vg + G₀)，AGC 反馈环路涉及检波器非线性、AD603 Vg-Gain 指数关系、环路有限增益，**G(Vd) 天然不是反比**。

### 三种模型

| 模型 | R² | MAE | MaxErr | 评价 |
|------|-----|-----|--------|------|
| G = a + b×Vd | 0.9654 | 2.67 | 5.77 | ❌ |
| ln(G) = a + b×Vd | 0.9949 | 0.80 | 2.85 | 🟡 物理意义好 |
| **G = c₀ + c₁·Vd + c₂·Vd²** | **0.9994** | **0.31** | **1.49** | ✅ **最优** |

### 物理注记

G_dB 与 Vd 之间确实是线性的（ln(G) = 8.534 − 0.009284×Vd, ln-domain R²=0.9968），这是 AD603 dB-线性增益特性决定的。但换算回线性域做 G 估算时，二次多项式在标定范围内更精确地逼近了这个指数曲线。

## 三、最终公式

```
G(Vd) = 474.947 − 1.31554 × Vd + 0.0009279 × Vd²

Vd 范围: [470, 660] mV
G 范围:  [11, 61]
R² = 0.99935
MAE = 0.31
残差 std = 0.40  (已触及测量噪声地板)
```

## 四、C 实现

见 `Core/Src/scope_calib.c` (已实现):

```c
float ScopeAGC_ComputeGain(float vd_mV)
{
    if (vd_mV < 470.0f) vd_mV = 470.0f;
    if (vd_mV > 660.0f) vd_mV = 660.0f;
    return 474.947464f
         + (-1.315542f) * vd_mV
         + 0.0009279000f * vd_mV * vd_mV;
}
```
