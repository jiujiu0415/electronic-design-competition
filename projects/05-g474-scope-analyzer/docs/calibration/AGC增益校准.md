## 四、C 实现

见 `Core/Src/scope_calib.c`:

```c
float ScopeAGC_ComputeGain(float vd_mV)
{
    if (vd_mV < 533.0f) vd_mV = 533.0f;
    if (vd_mV > 722.0f) vd_mV = 722.0f;
    return 578.79941065f
         + (-1.47806831f) * vd_mV
         + 0.00095825699f * vd_mV * vd_mV;
}
```
