# G题关键概念解释

> 写了给你看懂题目里的每个词，看完就不会被专业术语唬住了。

---

## 1. 周期信号 = 基波 + 谐波

### 用一句话说

题目给的信号**不是一个单纯的正弦波**，而是好几个频率的正弦波**混在一起**。

### 举个例子

题目示例：
```
u = U₁·sin(2π·10.5k·t) + U₃·sin(2π·31.5k·t) + U₄·sin(2π·42.0k·t) mV
```

这看起来吓人，其实就三个加法：

| 项 | 频率 | 叫什么 | 为什么 |
|----|------|--------|--------|
| U₁·sin(…) | 10.5kHz | **基波** | 最低频率，给信号定基调 |
| U₃·sin(…) | 31.5kHz | **3次谐波** | 31.5 = 10.5 × 3 |
| U₄·sin(…) | 42.0kHz | **4次谐波** | 42.0 = 10.5 × 4 |

**谐波就是基波的整数倍频率**。谐波加进去，波形就不再是标准正弦，而是某种"歪"的周期波形（方波、三角波等都含有谐波）。

### 题目说明第1条的解读

> uₐ 或 u_b 是由基波与 **1个或2个谐波分量**组合而成的周期信号

→ FFT 频谱里最多出现 **3 根谱线**（1根基波 + 1~2根谐波），不会是密密麻麻一堆。

### 你只需要做

FFT 做完后，在频谱里找到所有"峰"，按频率排成表：
```
10.5 kHz → 幅度 U₁
31.5 kHz → 幅度 U₃
42.0 kHz → 幅度 U₄
```
这就是题目要求的"显示各分量的幅值"。

## 2. 真有效值 (True RMS)

### 为什么强调"真"

普通的万用表测交流电压，默认假设你测的是**纯正弦波**，它只测峰值然后除以 √2（=峰值/1.414）。

但本题的信号是**基波+谐波的混合波形**，波形不是标准正弦。这时候**峰值/√2 这招不准**。

**真有效值 = 对原始波形老老实实积分算出来的值**。

### 公式

```
Vrms = √( (1/N) × Σ (v[n] - Vdc)² )
```

翻译成人话：
1. 把 ADC 采到的 N 个电压值每个减去直流分量
2. 每个平方
3. 全加起来除以 N
4. 开根号

### 在代码里怎么做

```c
// ADC 采了 2048 个点存在 adc_buf[] 里
// 先把 ADC 值转成电压：
//   V[n] = adc_buf[n] × 3.3 / 4096

float sum = 0;
for (int i = 0; i < 2048; i++) {
    float v = adc_buf[i] * 3.3f / 4096.0f;
    sum += v * v;              // 平方累加
}
float Vrms = sqrt(sum / 2048);  // 开根号 = 真有效值
```

## 3. 频率分辨率 500Hz

### 什么意思

"分辨率 500Hz" 就是说，你的装置**能区分两个频率，它们至少差 500Hz**。

差 200Hz 的两个频率信号 → 装置可以**混成一团**（不扣分）。
差 500Hz 以上的 → 装置必须**能分开显示**。

### 对 FFT 参数的决定

FFT 的频率分辨率 = **采样率 Fs / FFT 点数 N**

```
目标: Fs/N ≤ 500Hz

方案1: Fs=1MSPS, N=2048 → 1000000/2048 = 488Hz ✅
方案2: Fs=2MSPS, N=4096 → 2000000/4096 = 488Hz ✅
方案3: Fs=500kHz, N=1024 → 500000/1024 = 488Hz ✅
```

**结论**：2048 点 FFT 配 1MSPS 采样率就够。你在 04 项目已经做过 2048 点了。

## 4. 奈奎斯特采样定理

### 核心规则

> 采样频率 ≥ 信号最高频率 × 2

**为什么**：如果采样太慢，高频信号会"伪装"成低频信号。这就叫**混叠**。

### 举个例子

如果信号是 500kHz 的正弦波，但只以 600kHz 采样（不够 2 倍）：
- 500kHz 信号在采样后看起来像 **100kHz** 的信号（600-500=100）
- 你的 FFT 会告诉你"有个 100kHz 的信号"——这是假的！

### 本题的应用

| 要求 | 最高信号频率 | 最低采样率 | 建议采样率 |
|------|------------|-----------|-----------|
| 要求1 | 200kHz | >400kHz | 1MSPS |
| 要求2 | 500kHz | >1MHz | 2MSPS |
| 要求3 | 500kHz (+1MHz干扰) | >1MHz | 2MSPS + **FFT整数倍验证识别并排除干扰** |

## 5. 干扰抑制策略（要求3的关键）

### 干扰特性

要求3 的信号里有个 **≥1MHz 的干扰**，而且 200mVpp 比有用信号还大。

```
采样率 = 2MSPS → 奈奎斯特频率 = 1MHz
≥1MHz 干扰 → 混叠回 0~1MHz 频带
```

### 纯软件方案：FFT 整数倍验证 + 检波器交叉验证

题目给出了关键信息：
> 有用信号是基波 + 1~2个谐波，干扰是单频 200mVpp

混叠后的干扰在频谱中只是一根**孤立的谱线**，不满足整数倍关系。所以：

```
FFT 频谱:
  ┃         ?  ← 混叠干扰（孤峰，不在整数倍位置）
  ┃  ┃  ┃
  ┃  ┃  ┃      ← 基波 + 谐波（满足 f_k = k × f₁）
  ╋━━╋━━╋━━━━━━→ f
  
识别规则:
  ① 找最低频率峰 → 基频 f₁ ✓
  ② 在 f₁×k 位置搜索 → 谐波 ✓
  ③ 剩下的不满足整数倍的峰 → 干扰 ✗（排除）
```

**三层防御**（详见 `docs/要求3方案设计.md`）：
- 层① 整数倍关系验证：干扰峰不满足 f = k×f₁ → 排除
- 层② ADC2 检波器幅值对比：预知干扰 200mVpp，幅值不匹配的谱线标记可疑
- 层③ Parseval + Vpp 交叉验证：能量守恒校验，三层全过=HIGH置信度

### 为什么暂不加硬件滤波

| 理由 | 说明 |
|------|------|
| 干扰是单频固定幅值 | 频谱只多一根谱线，不是噪声底抬高 |
| 整数倍关系不可伪造 | 混叠不改变"基波+谐波满足整数倍"的特征 |
| 先跑通软件 | 软件逻辑验证后，实测看是否需要硬件辅助 |
| 如果真需要 | 一个 RC 低通（1电阻+1电容）就能大幅衰减 |

## 6. BNC 接头 / 50Ω 匹配

### BNC 是什么

```
就是一种转一下就能卡住的同轴电缆接头。
示波器和信号发生器上常见的那个圆圆的接头就是 BNC。
```

### 50Ω 是什么意思

信号源输出内部串联了 50Ω 电阻。你的装置的输入端的输入阻抗应该尽量高（MΩ 级），用电压测量模式而不是功率匹配模式。ADC 输入端本身已经高阻了，**加一个电压跟随器（运放射随）就行**。

### 你需要做的

- 淘宝买 BNC 母座（PCB 焊接型）
- 电路板上焊好 BNC 座
- BNC 座芯 → 你的信号调理电路输入端
- BNC 座外壳 → GND

## 7. 电压频谱图

### 题目要求什么

> "定性显示电压频谱图：正频率轴上离散谱线的根数、谱线频率相对位置、谱线长度之间的相对比例大体吻合即可"

### 翻译

``` 
     ^ 幅度
     │
     │  ┃                   ┃
     │  ┃         ┃         ┃
     │  ┃         ┃         ┃          ← 谱线高度 = 各分量幅值占比
     │  ┃         ┃         ┃
     └──╋─────────╋─────────╋──────→ f
      10.5k     31.5k     42.0k

 坐标轴可不加刻度！
 谱线根数对 ✓  
 谱线靠左/靠右的相对顺序对 ✓
 高的高、矮的矮，比例不歪 ✓
```

**这就是送分题，比你在 04 项目做的 Bode 图简单 10 倍。**

## 8. 1个或3个完整周期显示

### 操作逻辑

按键按一次 → 屏幕显示**1个完整周期**波形
再按一次   → 屏幕显示**3个完整周期**波形
再按       → 切换回 1 个周期

### 怎么实现

1. FFT 测出基频 f₁
2. 周期 T = 1/f₁
3. 每周期采样点数 = Fs × T
4. 1周期 = 从 ADC 缓冲区截取 N 个点画在屏幕上
5. 3周期 = 截取 3N 个点

## 9. Vpp（峰峰值）/ Urms（有效值）/ 基频 f₁

| 参数 | 全称 | 怎么算 | 误差要求 |
|------|------|--------|---------|
| **Vpp** | Voltage peak-to-peak 峰峰值 | ADC 采样值的 max - min，转成电压 | ≤5mV |
| **Vrms** | Voltage RMS 真有效值 | √(Σv²/N) | ≤5mV |
| **f₁** | Fundamental frequency 基频 | FFT 频谱中最低频率的峰的位置 | ≤1kHz |

### Vpp 为什么要 ≤5mV 精度

5mV / 100mV = 5%（最严情况），对于 12-bit ADC（3.3V/4096=0.8mV）来说**完全够**。

12-bit ADC 每个 LSB ≈ 0.8mV，所以在 100mV 信号上，5mV=6个LSB。硬件上注意：
- 信号不能太小（要求1最小100mVpp，还可以）
- 运放给适当的增益让信号用满 ADC 量程

## 10. 裸芯片 G474RET6（不是 NUCLEO 板）

这是你告诉我的重要信息。和 NUCLEO 板有这些区别：

### 硬件差异

| | NUCLEO-G474RE | 你自己的 G474RET6 板 |
|---|---------------|---------------------|
| 晶振 | HSE 8MHz (ST-LINK MCO) | **无外部晶振，用 HSI (16MHz)** |
| 调试 | 板载 ST-LINK/V3 | **需外接 ST-LINK 排针 (SWDIO/SWCLK/GND)** |
| 串口 | ST-LINK VCP (虚拟串口) | **需独立的 USB-TTL 模块** |
| 供电 | USB 5V → 板载 LDO | **需要自己的 5V→3.3V 电路** |
| 复位 | 板载复位按钮 | 需上拉电阻 + 按键（可选） |
| BOOT0 | 跳线帽 | 默认下拉到 GND（Flash 启动） |

### 外接调试/串口最少引脚

```
ST-LINK (调试+烧录):
  SWDIO  ── PA13
  SWCLK  ── PA14
  GND    ── GND
  3.3V   → ST-LINK 给板子供电（调试时）

USB-TTL (串口):
  TX ── PA2 (USART2_TX)
  RX ── PA3 (USART2_RX) ← 非必须，只要发数据给电脑就行
  GND ── GND
```

### CubeMX 关键变化

| 配置项 | NUCLEO | 裸芯片 |
|--------|--------|--------|
| RCC HSE | BYPASS Clock Source (来自MCO) | **Disable** |
| RCC HSI | 不用 | **开启** |
| PLL Source | HSE | **HSI** |
| SWD 接口 | 默认 | **在 SYS → Debug 选 Serial Wire** |
| USART2 引脚 | 固定 PA2/PA3 | **还是 PA2/PA3** |
| 供电 | USB | **外部 5V → 板上 3.3V LDO** |

### 上电启动条件

裸芯片最少需要：
```
① 3.3V 供电 (VDD=3.3V, VDDA=3.3V)
② VDD 和 VDDA 的去耦电容 (100nF + 10μF, 离引脚越近越好)
③ NRST 脚接 10kΩ 上拉到 3.3V
④ BOOT0 接 10kΩ 下拉到 GND (从 Flash 启动)
⑤ SWDIO/SWCLK 引出给 ST-LINK
```

如果 NRST 或 BOOT0 悬空 → **无法烧录**。

## 11. 幅值 (Amplitude) vs 峰峰值 (Vpp)

### 这是两个最容易搞混的概念

```
  V
  ↑
  │       ⋰              ← 正弦波围绕 Vdc 上下摆动
  │     ⋰   ⋰
  │   ⋰       ⋰
  ├──⋰─────────⋰─────    ← Vdc (直流偏置)
  │             ⋰
  │               ⋰
  └──────────────────→ t
  
  幅值 A = 零到峰的高度 ("一半的高度")
  峰峰值 Vpp = 两个峰之间的距离 ("最高的减最低的")
```

### 数学关系（纯正弦波）

| 名称 | 符号 | 含义 | 和幅值 A 的关系 | 数字例（A=0.5V） |
|------|------|------|----------------|----------------|
| **幅值** | A 或 Vpeak | 从零点到波峰的距离 | A | **0.5V** |
| **峰峰值** | Vpp | 从波谷到波峰的距离 | Vpp = **2×A** | **1.0V** |
| 有效值 | Vrms | 等效发热值 | Vrms = A/√2 ≈ 0.707×A | **0.354V** |

```
  A = Vpp / 2      ← 幅值 = 峰峰值的一半
  Vpp = 2 × A      ← 峰峰值 = 幅值的两倍
  Vrms = Vpp / (2√2) = Vpp / 2.828
```

### 题目里的"幅值"是什么意思

题目要求中反复出现 **"显示 uₐ 的电压频谱各分量的幅值"**。

频谱中的"幅值"指的是**每个频率分量的正弦波峰值（Vpeak）**，不是峰峰值。

```
例: 信号 = 0.5V·sin(2π·10k·t) + 0.1V·sin(2π·30k·t)

频谱显示:
  10.0 kHz → 幅值 0.5 Vpeak   (不是 1.0 Vpp)
  30.0 kHz → 幅值 0.1 Vpeak   (不是 0.2 Vpp)
```

### 为什么我的代码用 Vpeak 而不是 Vpp

FFT 输出的是**正弦分量的峰值幅度**，这是国际通用的频谱表示方式。如果用 Vpp，出来的值会是实际的 2 倍，不符合题目示例里给的标注格式。

### 快速区分口诀

| | 提问 | 答案 |
|----|------|------|
| 幅值 A | "波形有多高？" | 零点到峰顶 |
| 峰峰值 Vpp | "波形最高减最低差多少？" | 2 个幅值 |
| 有效值 Vrms | "相当于多少直流电的发热？" | 约 0.7 个幅值 |

## 总结口诀

| 概念 | 一句话 |
|------|--------|
| 基波+谐波 | 好几个整数倍频率的正弦波混在一起 |
| 真有效值 | 不是 Peak/√2，是 Σv²/N 再开根号 |
| 幅值 vs 峰峰值 | 幅值=到零点的距离，峰峰值=2倍幅值 |
| 频率分辨率 | Fs/N，题目要 ≤500Hz → 2048点+1M够用 |
| 奈奎斯特 | 采样率 > 2×最高频率，否则"伪装" |
| 抗混叠 | ADC 前加低通，挡住 1MHz 干扰 |
| BNC/50Ω | 信号输入接头 + 阻抗匹配，加个射随 |
| 频谱图 | 几根竖线，位置对+高低对即可，不需坐标 |
| 裸芯片 | HSI、外接ST-LINK、外接串口、注意NRST/BOOT0 |
