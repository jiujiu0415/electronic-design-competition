## <a id="一"></a>一、大白话：什么是乘法器？

### 1.1 最直观的类比

想象你有一台**音量旋钮**：

```
音频信号  ────▶  [ 音量旋钮 ] ────▶  喇叭

旋钮位置决定声音大小。
```

这个"旋钮"就是一个**乘法器**：

```
输出 = 音频信号 × 旋钮位置

旋钮拧大（×0.8）→ 声音大
旋钮拧小（×0.1）→ 声音小
```

AD835 就是把两个**电压**乘在一起，结果实时从引脚上输出。

### 1.2 和"加法器""放大器"有什么区别？

```
加法器  → 输出 = A + B     （两个信号混叠在一起）
放大器  → 输出 = A × 常数   （把一个信号放大固定倍数）
乘法器  → 输出 = A × B     （两个信号实时相乘，B 也可以是变化的信号！）
```

**乘法和加法的区别，就是调制和混音的区别：**

```
加法:  1000Hz + 100000Hz → 同时听到 1k 和 100k（混音）
乘法:  1000Hz × 100000Hz → 得到 99k + 101k（频率搬移了！）

这就像：
  "把糖和咖啡分别倒进杯子里" → 加法（混在一起但互不影响）
  "把糖和咖啡一起搅"         → 乘法（产生新的东西！）
```

### 1.3 一个生活中的例子

假设你要**测量一个未知电阻的功率**：

```
功率 = 电压 × 电流

如果电压 = 5V，电流 = 0.2A
功率 = 5 × 0.2 = 1W

但如果是交流？电压和电流都在变？

功率(t) = 电压(t) × 电流(t)

你需要一个"时时刻刻都在做乘法的装置" → AD835。
```

## <a id="二"></a>二、数学原理：W = X × Y + Z

### 2.1 AD835 的公式（差分输入版本）

```
W = (X1 - X2) × (Y1 - Y2) × U + Z

简化版（接地 X2、Y2，令 U=1）：
W = X1 × Y1 + Z
```

| 引脚 | 含义 | 典型接法 |
|------|------|---------|
| X1, X2 | X 差分输入 | X1 接信号，X2 接地 |
| Y1, Y2 | Y 差分输入 | Y1 接信号，Y2 接地 |
| Z | 偏移输入 | 接地（0V） |
| W | 输出 = X×Y+Z | 接示波器 / ADC |

### 2.2 几个最基础的数值例子

```
直流 × 直流 = 直流：
  X = 0.5V, Y = 2V   →  W = 0.5 × 2 = 1V
  X = -0.5V, Y = 2V  →  W = -0.5 × 2 = -1V   ← 支持负电压！

直流 × 交流 = 放大/缩小：
  X = 2V（直流）, Y = 0.1V 正弦波(1kHz)
  → W = 0.2V 正弦波(1kHz)   ← 幅度缩小了 5 倍

交流 × 交流 = 产生新频率：
  X = 1V 正弦波(1kHz), Y = 1V 正弦波(100kHz)
  → W = 包含 99kHz + 101kHz 的信号   ← 频率变了！
```

> **关键洞察**：直流 × 交流 = 改变幅度（线性）；交流 × 交流 = 改变频率（非线性）。这两条路通向完全不同的应用。

## <a id="三"></a>三、AD835 能做什么？—— 六把"万能工具"

### 3.1 振幅调制（AM 调制）

```
原理：低频信号 × 高频载波 → 调幅波

   音频(A)        载波(B)          调幅波(W=A×B)
   ╱╲   ╱╲        ││││││││││        ╱│╲   ╱│╲
  ╱  ╲ ╱  ╲     ││││││││││││     ╱ │ ╲ ╱ │ ╲
 ╱    ╲    ╲   ││││││││││││││  ╱  │  ╲  │  ╲
          ╱     ││││││││││││││      │  │   │
                 高频固定        包络 = 音频形状
                                 载波 = 高频填充
```

**有什么用？**
- 无线通信：把语音"骑"到高频载波上发射出去
- 电赛中：产生各种调制信号，测试接收机性能

### 3.2 混频/变频（频率搬移）

```
原理：sin(f₁) × sin(f₂) = ½[cos(f₁-f₂) - cos(f₁+f₂)]

输入 X: sin(2π × 1000t)   ← 1kHz
输入 Y: sin(2π × 100000t) ← 100kHz

输出 W 包含:
  f₁+f₂ = 101kHz   ← 和频
  f₁-f₂ =  99kHz   ← 差频

用滤波器选其中一个 → 你得到了一个新的频率！
```

**有什么用？**
- 把低频信号"搬"到高频发射（上变频）
- 把高频信号"搬"到低频处理（下变频，超外差接收机）
- 电赛通信题的核心技术

### 3.3 鉴相（测相位差）

```
原理：两个同频率信号相乘，结果的直流分量 = 相位差的比例

  X = A·sin(ωt)
  Y = B·sin(ωt + φ)    ← Y 比 X 晚了 φ 度

  W = A·sin(ωt) × B·sin(ωt + φ)
    = ½AB[cos(φ) - cos(2ωt + φ)]
         ↑这个不随时间变   ↑这个频率是 2ω

  滤掉 2ω 分量后：W_dc = ½AB·cos(φ)

  如果 φ=0°    → cos(0°)=1   → W_dc = 最大正电压
  如果 φ=90°   → cos(90°)=0  → W_dc = 0
  如果 φ=180°  → cos(180°)=-1 → W_dc = 最大负电压
```

**有什么用？**
- 锁相放大器（LIA）—— 从噪声中提取微弱信号
- 阻抗测量 —— 测电容/电感的相位
- 锁相环（PLL）—— 频率合成
- **这是仪表题最高级的测量技术之一**

### 3.4 倍频

```
原理：同一个信号同时接到 X 和 Y

  X = Y = sin(ωt)

  W = sin(ωt) × sin(ωt)
    = sin²(ωt)
    = ½[1 - cos(2ωt)]
        ↑直流  ↑这个频率是 2ω（倍频！）

  滤掉直流后：得到 2ω 频率的信号
```

**有什么用？**
- 从 10MHz 晶振得到 20MHz
- 频率合成器
- 但注意：sin² 产生的是二次谐波，需要滤波

### 3.5 功率计算

```
原理：功率 = 电压 × 电流

  电压信号 ──▶ X1
  电流信号 ──▶ Y1（通过采样电阻转换）
  
  W = V(t) × I(t) = P(t)   ← 瞬时功率

  对 P(t) 取平均 → 平均功率
```

**有什么用？**
- 功率计（电赛仪器题常考）
- 电能质量分析
- 负载特性测量

### 3.6 压控放大器（VCA）

```
原理：信号 × 直流控制电压 = 幅度受控的信号

  X = 正弦波（需要被控制幅度的信号）
  Y = 直流电压 Vc（来自 DAC 或电位器）

  W = 正弦波 × Vc

  Vc = 1V  → 输出全幅度正弦
  Vc = 0.5V → 输出半幅度正弦
  Vc = 0V  → 输出 = 0（静音）
```

**有什么用？**
- 自动增益控制（AGC）
- 音量控制
- 调幅波的调制深度控制

## <a id="五"></a>五、为什么仪表方向需要 AD835？

### 5.1 仪表题的核心能力

电赛仪表方向的题目，本质上考察这几件事：

```
┌────────────────────────────────────────────────────┐
│                                                    │
│   电信号 ──▶ [调理电路] ──▶ [ADC采集]              │
│                                │                    │
│                                ▼                    │
│                           [数字处理]                │
│                                │                    │
│                                ▼                    │
│                           [显示结果]                │
│                                                    │
│   但如果信号太小，被噪声埋住了怎么办？               │
│         │                                          │
│         ▼                                          │
│   [锁相放大器] ← 这就是乘法器的"成名绝技"          │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 5.2 锁相放大器（LIA）—— 乘法器在仪器领域的终极应用

**问题**：你需要测一个 1μV 的微弱信号，但噪声有 10mV。信噪比 = -80dB，用普通方法根本没戏。

**锁相放大器的思路**：

```
                    噪声 (10mV)
                        +
    微弱信号 (1μV) ──▶ [加法] ──▶ [AD835 ×] ──▶ [低通滤波] ──▶ 干净的直流电压
                         ↑                          ↓
                    参考信号 (同频)            只保留直流分量
                         ↑                    (噪声 × 参考 = 0)
                    你主动加进去的
```

**原理**：

1. 给被测系统一个已知频率的激励信号（参考）
2. 输出信号 = 有用信号（和参考同频）+ 噪声（各种频率都有）
3. 把输出信号 × 参考信号 → 有用信号 × 参考 → 产生直流 + 倍频
4. 低通滤波 → 只留直流 → 直流电压 = 有用信号的幅度 × cos(相位差)
5. 噪声 × 参考（频率不匹配）→ 只产生交流 → 被低通滤波器干掉

**效果**：能从比噪声小 100 万倍的信号中提取出有用信息。

**电赛中的应用**：

| 题号 | 年份 | 题目 | 乘法器参与 |
|------|------|------|-----------|
| 典型 | — | 微弱信号检测装置 | 锁相放大器核心 |
| 典型 | — | 简易阻抗分析仪 | 鉴相测阻抗角 |
| 典型 | — | 数字功率计 | 电压×电流实时相乘 |
| 典型 | — | 电能质量监测 | 有功/无功功率计算 |

## <a id="七"></a>七、核心参数速查

### AD835 关键参数

| 参数 | AD835 | 通俗理解 |
|------|-------|---------|
| 带宽 | **250 MHz** | 能处理多快的信号（很高的天花板） |
| 压摆率 | 1000 V/μs | 输出电压能多快变化 |
| 输入范围 (X,Y) | **±1V** (典型) | 超过会失真，请把信号缩放到这个范围 |
| 输出范围 | **±2.5V** | 能输出的最大电压摆幅 |
| 乘法增益 U | **1.05** (典型) | W = 1.05 × X × Y，接近 1 |
| 供电电压 | **±5V** | **需要双电源！不像 AD9833 只用 3.3V** |
| 静态功耗 | ~150mW | 不怎么耗电 |
| 封装 | 8-PDIP / 8-SOIC | 可以手焊 |

### ⚠️ 重要提醒：供电问题

```
AD9833: 3.3V 单电源  ✅
AD835:  ±5V 双电源   ⚠️ 多了一路负电压！

需要：+5V, GND, -5V 三根电源线

常用方案：
  ICL7660 电荷泵：+5V 输入 → -5V 输出（最简单）
  TPS65133：±5V 输出（专业方案）
  两个电池串联：中间抽头当 GND（电赛应急方案）
```

## 总结：记住这三句话就行

```
1. AD835 就是一个实时的电压乘法器：输出 = X × Y + Z

2. 它能做的六件事：
   ├─ 调制（AM）
   ├─ 混频（频率搬移）
   ├─ 鉴相（测相位）
   ├─ 倍频（×2）
   ├─ 功率计算（V×I）
   └─ 压控放大（VCA）

3. 仪表方向最重要的应用是锁相放大器：
   用乘法 + 滤波从噪声里提取微弱信号
```
